OJEE STUDENTS ZONE — MOBILE ANIMATED WEBSITE
================================================

Folder
------
OJEE_Students_Zone/
  index.html

  script.js
  README.txt
  Our Achivers.pdf

How to run
-----------
1. Keep all five files in the same folder.
2. Open index.html in a modern browser.
3. For the most reliable PDF preview and local development, use a simple local server
   (for example, VS Code Live Server) instead of opening the HTML directly.

Deployment
----------
This is a static website. Upload the five files together to any static host such as
GitHub Pages, Netlify, Vercel or standard web hosting.

Important
---------
- The PDF filename is intentionally EXACTLY: Our Achivers.pdf
- Do not rename the PDF unless you also update both PDF references in index.html.
- The contact buttons use the supplied phone, WhatsApp, email, YouTube and Play Store links.
- No phone number or email address is displayed as visible contact text.
- No institute logo image, teacher photo, location section or heavy media is used.
- Google Fonts are loaded from the web for Outfit and DM Sans. If offline, the page
  falls back to system sans-serif fonts.
- The mobile PDF experience intentionally presents an "OPEN FULL PDF" button because
  embedded PDF viewers are inconsistent on mobile browsers.

Accessibility
-------------
Semantic sections, labelled interactive controls, keyboard focus styles, a labelled
mobile menu, and prefers-reduced-motion support are included.

Performance
-----------
Animations are primarily CSS transform/opacity animations. JavaScript uses
IntersectionObserver for reveal effects and requestAnimationFrame only for the
desktop pointer/parallax effect.
