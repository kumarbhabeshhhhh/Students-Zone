The predictor is integrated into the existing design and does not replace the site's animation/transition system.

IMPORTANT DATA NOTE:
The included starter dataset contains only verified records currently added to predictor-data.js. Add additional verified OJEE LE-Tech records there before presenting broader historical results.

The predictor has two modes:
1. I KNOW MY GENERAL RANK — finds matching historical records.
2. FIND REQUIRED RANK — shows historical opening/closing ranks for a selected college and branch.

The result is an approximate historical analysis, not an official OJEE prediction or admission guarantee.
